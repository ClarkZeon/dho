# 가속도의 비밀 (원본 실험 정리)

> 작성: 곽훈필 · 2020-04-22 (이후 추가 측정)

> Pilgrim 공식화 문서: [../ship-acceleration.md](../ship-acceleration.md)

실험으로 확인된 사실과 표입니다. 구현 시에는 상위의 전개식을 우선하세요.

---

## 1. 측정 방법

- 한 캐릭터: 장갑·적재 위주로 맞춤
- 다른 캐릭터: 다양한 변수 적용
- **두 캐릭터를 동시에 출발**시켜 비교

### 유효 측정 조건

1. Insert로 돛을 편 뒤 출발 지연이 두 캐릭터 간 동일할 것
2. 출발 후 옆 배가 앞뒤로 흔들리는(렉처럼 보이는) 움직임이 없을 것

### 키 입력 순서

1. 출항 후 정박 상태에서 증기기관 / 노젓기 사용
2. 급가속: `W`로 돛 한 칸만 올렸다 급가속 → 바로 내림
3. 완전 정박 확인 후 `Insert`

## 2. 가속과 무관한 요소

- 필요 선원 (1명이어도 동일)
- 부관 선박 (종류·유무 무관, 증기선 부관도 무관)
- 조력 (80 vs 105 동일)
- 돛 수치, 선회, 내파
- 돛 조종, 풍신, 베이옷, 대학스킬 등 **항해 속도** 보너스
- 강화키, 조타

---

## 3. 기본 가속도

- 증기선 제외 **모든 배의 0단계 기준이 동일**
- 증기선은 석탄 유무에 따라 별도 (아래 13절)

---

## 4. 적재량

- **강화 제외** 순수 선실 + 포실 + 창고 합
- **100당 가속 -1**

| 적재 | 단계 |
|------|------|
| 0~99 | 0 |
| 100~199 | -1 |
| 200~299 | -2 |
| … | … |
| 1400~1499 | -14 |
| 1500 | -15 (확인) |

식: `-int(b / 100)`

---

## 5. 장갑

- 기본 장갑 + 추가 장갑 (강화 수치 무관)
- **5단위**로 +1 (장갑 10부터)

| 장갑 | 단계 |
|------|------|
| 10~14 | +1 |
| 15~19 | +2 |
| … | … |
| 105~109 | +20 |
| 110~114 | +21 |
| 115~119 | +22 (가능) |

식: `int((a - 5) / 5)`  
(장갑 5 이하는 0으로 취급되는 형태)

---

## 6. 직업 · 해역조사 · 가강 · 급가속

| 요소 | 효과 | 비고 |
|------|------|------|
| 모험계 직업 | +1 | 수습 모험가 포함. 교역·전투 0 |
| 해역조사 | **+2** | 기존에 +1로 알려졌으나 +2로 확인 |
| 가속강화 1 | +3 | 가강2·3도 각각 +3으로 알려짐 |
| 가강 + (추가장갑 또는 적재 변경으로 가속↑) | **+0.5** | 모험 직업이어도 추가됨 (2020-09-30) |
| 급가속 | +6 | |

## 7. 증기기관 (범선 등)

고정값이 아니라 **\(X\)** (적재+장갑+직업+급가속 합)에 따라 변동.

해역조사·가강은 이 \(Y\) 구간에는 **영향 없음**.

| X | 증기기관 보너스 |
|---|----------------|
| -13 | +3 |
| -12 | +3 |
| -11 | +3.5 |
| -10 | +4 |
| -9 | +4 |
| -8 | +4.5 |
| … | X가 2 증가할 때마다 대략 +1 (홀수 X에서 .5) |
| 20 | +14 |
| 21 | +14 (확인) |

전개식(Pilgrim):

```text
Y = int((X + 23) / 3) - ((X+23)%3==0 ? 0.5 : 0)
```

### 예시: 특수 롱 스쿠너

조건: 25적다, 가강1, 20개삼판×3, 해역조사, 급가, 증기, 모험계

```text
X = -4 + 14 + 1 + 6 = 17
증기 = +13 → 17+13 = 30
해역+가강1 = +2+3 → 35
가강+추가장갑 0.5 → 35.5
```

## 8. 노젓기 (연성) — 갤리

역시 \(X\)에 연동. 급가속도 \(X\)에 포함됨 (2020-04-30 확인).

| X (적재+장갑+직업[+급가]) | 노젓기 보너스 |
|---------------------------|---------------|
| -7 | +14 |
| 0 | +21 |
| 12 | +33 (확인) |

전개식: `Y = X + 21`

랭크(12 vs 18, 14 vs 21)는 가속도 차이 없음.

### 비연성 노젓기

증기기관과 **동일** (2020-09-30 확인).

### 예시: 로나갤

**예시1** 25적다, 가강1, 2개삼판×3, 해역, 노젓, 전투

```text
X = -5 + 8 + 0 = 3
노젓 +24 → 27
해역+가강 → 32
+0.5 → 32.5
```

**예시2** 25적다, 20개삼판×1, 해역, 노젓, 급가, 전투

```text
X = -5 + 11 + 0 + 6 = 12
노젓 +33 → 45
해역 +2 → 47
```

## 9. 증기선

- **석탄 없음**: 가속 매우 낮게 고정, 추가장갑 등에도 거의 불변
- **석탄 있음**: \(X\)(+증기기관)에 따라 단계가 크게 변함  
  \(X\) ±1마다 추가분이 ±2 / ±4 교대
- 해역조사는 이 변환표에는 영향 없고, 예시에서는 최종에 +2
- 가강은 원 실험 시 미확인

| X(+증기 반영 후) | 석탄 시 실제 단계 |
|------------------|-------------------|
| -13 | 11 |
| -12 | 14 |
| -11 | 19 |
| -10 | 22 |
| -9 | 27 |
| -8 | 30 |
| -7 | 35 |
| -6 | 38 |
| -5 | 43 |
| -4 | 46 |

계산상 0단계 기준 ≈ **62** (석탄 기본).

### 예시: 클레르몽

25적업, 2개삼판×1, 증기기관, 해역, 교역

```text
X = -15 + 3 + 0 + 0 = -12
증기 +3 → -9 → 표상 27
해역 +2 → 29
```

## 10. 최고 가속단계

- **46단계**가 상한 (항해·전투·환수전 동일)
- 46.5와 48이 같은 체감 가속을 보인 사례 → 실효 상한 46으로 결론

## 11. 기타

- **이상한 바다** 귀빈용 비늘 재질: 가속 +4 (연성 노젓기 \(Y\) 변화에는 미포함). 축전·제례·야전도 동일 추정.
