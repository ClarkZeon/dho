# 선박 가속도 계산식

> 앱의 **선박 가속도 계산** 기능 구현용 공식 문서입니다.  
> 최종 정리: Pilgrim · 실험 기반: 곽훈필  
> 원문: [인벤 18320](https://www.inven.co.kr/board/dho/498/18320) · [인벤 18309](https://www.inven.co.kr/board/dho/498/18309)

## 개요

최종 가속단계 \(A\) 는 선종(갤리 / 범선 / 증기선)에 따라 달라지며,  
공통으로 **1차 가속단계 \(X\)** 를 구한 뒤 스킬·가강 보너스를 더합니다.

- **상한**: \(A \le 46\) (항해·전투 공통)
- `int(x)` = 소수점 이하 버림

---

## 입력 변수

| 변수 | 의미 | 값 |
|------|------|----|
| `a` | 기본 장갑 + 추가 장갑 | 정수 (강화치 제외) |
| `b` | 총 적재 (선실+포실+창고) | 정수 (강화치 제외, 적다/적업 수치) |
| `c` | 모험계 직업 | `1` 모험가 / `0` 상인·군인 |
| `d` | 급가속 | `6` 사용 / `0` 미사용 |
| `e` | 해역조사 | `2` ON / `0` OFF |
| `f` | 가속강화 그레이드 | `1` / `2` / `3` (없으면 아래 Z에서 제외) |
| `g` | 가강 + 추가장갑 보너스 | `0.5` (가강 장착 + 추가장갑 시) / `0` |

### 주의

- **전투 중** 계산 시 급가속을 쓰지 않으므로 `d = 0` 으로 둔다.
- 가속강화가 없으면 `f`·`g` 항을 0으로 처리한다.

---

## 1단계: \(X\) (공통 1차 가속단계)

장갑 + 적재 + 모험직업 + 급가속

```text
X = int((a - 5) / 5) - int(b / 100) + c + d
```

### 분해 의미

| 요소 | 식 | 비고 |
|------|----|------|
| 장갑 | `int((a - 5) / 5)` | 장갑 10~14 → +1, 15~19 → +2 … |
| 적재 | `-int(b / 100)` | 100마다 -1 |
| 직업 | `+c` | 모험계만 +1 |
| 급가속 | `+d` | 사용 시 +6 |

---

## 2단계: \(Y\) (스킬 보너스)

### 갤리 — 노젓기 (연성)

```text
Y = X + 21
```

즉 연성 노젓기 기여분 = `X + 21` (최종식에서는 \(2X + 21\) 형태로 합쳐짐).

### 범선 — 증기기관 / 노젓기 (비연성)

```text
raw = (X + 23) / 3
Y   = int(raw) - (raw가 정수이면 0.5 else 0)
```

### 증기선 — 석탄 연료 소지 시

```text
Y = 3 * X + 63 - (X가 짝수이면 1 else 0)
```

- 석탄이 없으면 가속이 매우 낮게 고정되며, 일반 변수로 잘 변하지 않음.
- 해역조사·가강은 증기선 \(Y\) 산출에 **영향 없음** (아래 Z 참고).

---

## 3단계: \(Z\) (해역조사 · 가속강화)

### 갤리 / 범선

```text
Z = e + 3 * f + g
```

| 항목 | 값 |
|------|----|
| 해역조사 | +2 |
| 가강 1/2/3 | 각각 +3 (그레이드당) |
| 가강 + 추가장갑 | +0.5 |

### 증기선

```text
Z = 0
```

(해역조사는 최종에 따로 더하는 실험 예시도 있으나, Pilgrim 최종식에서는 증기선 `Z = 0`)

---

## 최종 가속단계 \(A\)

일반형:

```text
A = X + Y + Z   (상한 46)
```

선종별 전개식:

### 갤리

```text
A = Z + 2 * X + 21
```

### 범선

```text
A = Z + X + int((X + 23) / 3)
  - ( (X + 23)이 3의 배수이면 0.5 else 0 )
```

원문 표기:

```text
A = Z + 1 * X + int((X + 23) / 3) - 0.5
```

단, `-0.5` 는 **`(X + 23) / 3` 이 정수일 때만** 적용.

### 증기선 (석탄 소지)

```text
A = 4 * X + 63 - (X가 짝수이면 1 else 0)
```

## 구현용 의사코드

```ts
type ShipType = 'galley' | 'sail' | 'steam'

function floor(n: number) {
  return Math.trunc(n) // 양수 기준 버림. 음수 X 고려 시 Math.floor 검토
}

function calcX(a: number, b: number, c: 0 | 1, d: 0 | 6) {
  return floor((a - 5) / 5) - floor(b / 100) + c + d
}

function calcZ(
  ship: ShipType,
  e: 0 | 2,
  f: 0 | 1 | 2 | 3,
  g: 0 | 0.5,
) {
  if (ship === 'steam') return 0
  return e + 3 * f + g
}

function calcAccel(input: {
  ship: ShipType
  a: number // 장갑
  b: number // 적재
  c: 0 | 1  // 모험직업
  d: 0 | 6  // 급가속
  e: 0 | 2  // 해역조사
  f: 0 | 1 | 2 | 3 // 가강
  g: 0 | 0.5 // 가강+추가장갑
  coal?: boolean // 증기선 석탄
}) {
  const { ship, a, b, c, d, e, f, g } = input
  const X = calcX(a, b, c, d)
  const Z = calcZ(ship, e, f, g)

  let A: number
  if (ship === 'galley') {
    A = Z + 2 * X + 21
  } else if (ship === 'sail') {
    const t = (X + 23) / 3
    A = Z + X + floor(t) - (Number.isInteger(t) ? 0.5 : 0)
  } else {
    // steam + coal
    if (!input.coal) throw new Error('석탄 없음: 별도 저가속 고정 처리 필요')
    A = 4 * X + 63 - (X % 2 === 0 ? 1 : 0)
  }

  return Math.min(A, 46)
}
```

## 엑셀 계산표 사용법 (원 첨부)

첨부: [`sources/ship-acceleration-table.xlsx`](./sources/ship-acceleration-table.xlsx)

- 적업/적다 체크 → 적재에 따른 가속단계 자동 계산  
  - 체크: 25적업 기준  
  - 해제: 25적다 기준
- 필터로 정렬해 순위 확인 가능
- 신규 선박: 기본 수치만 입력하면 2차 데이터 자동 계산

### 리스트 범위 (작성 시점)

| 선종 | 포함 |
|------|------|
| 범선 | 대형2종 거의 전부(조타숙련 200), 주요 대형1종(160): 경계형 코르벳, 산타 마리아, 바운티, 엔데버 등 |
| 갤리 | 나폴리탄 갤리스, 몰타 기사단 갤리, 오스만 갤리온, 라 모르, 라 르와이얄, 장교용 라레알, 거북선 등 |
| 증기선 | 리스트 미포함 |

### 4G 강화한계 기준값 (원문)

| 분류 | 돛 | 창고 | 선회/내파 |
|------|----|------|-----------|
| 범용 | +140 | +49 | +27 |
| 모험 | +160 | +49 | +28 |
| 교역 | +140 | +51 | +26 |
| 전투 | +140 | +49 | +26 |

분류 오류 시 돛합 최대 ±40, 창고 최대 ±2 오차 가능.

### 주의 사항

- 수치 출처: 조이 / 두부 사이트
- 붉은색 수치는 불확실 → 검증 필요
- 한·일·글로벌 출시 차이에 따라 미출시 선박이 포함될 수 있음
